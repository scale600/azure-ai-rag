About

This is an AI-powered member support assistant for a financial institution. It answers questions about fees, accounts, cards, loans, KYC, and FAQs using RAG (Retrieval-Augmented Generation).

Instead of replying from the model's general knowledge, the assistant first retrieves the most relevant passages from a knowledge base of 31 official documents, then generates each answer grounded in those sources — with citations you can verify.

Built with Azure AI

  • Azure OpenAI — GPT-4.1-mini (answer generation) and text-embedding-3-small (embeddings)
  • Azure AI Search — hybrid vector + keyword retrieval
  • Azure App Service + Static Web App — Flask RAG API and this chat UI

Prototype — demonstrates RAG-based AI member support on Azure.

How it works

This assistant uses RAG (Retrieval-Augmented Generation) — an AI pattern that grounds responses in a trusted knowledge base rather than relying on the model's general knowledge alone.

  1. Ingest & index

    The 31 official documents are split into chunks, converted into vectors with text-embedding-3-small, and stored in Azure AI Search.

  2. Retrieve

    Your question is embedded and matched using hybrid search — vector similarity plus keyword (BM25), fused with RRF — to surface the 5 most relevant passages.

  3. Generate

    GPT-4.1-mini reads only those retrieved passages and writes a grounded answer with citations. If the answer isn't in the documents, it says so instead of guessing.

Why RAG? It keeps answers accurate and traceable — every response points back to a source document, which reduces hallucination.
